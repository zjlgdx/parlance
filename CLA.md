## How to sign

You sign this Agreement by adding a file named `cla/signatures/<id>.md` to
the repository in your first pull request, where `<id>` is your numeric
GitHub user id. The file must contain exactly the statement below, with only
the five bracketed fields replaced: your full name, your numeric GitHub user
id, your GitHub login at the time of signing, the version of this Agreement
(the `Version:` line above), and the signing date in `YYYY-MM-DD` form. No
email address or postal address is collected. The pull request that adds
the file must be opened from the GitHub account whose numeric id is in
the file. Adding the file in that pull request is your electronic
signature of this Agreement and your acceptance of its terms, effective
on the date in the file or the date you first submitted a Contribution,
whichever is earlier. The file and the version of this Agreement it
names remain in the repository history as the record of your signature;
keep a copy for your records.

This Agreement is signed by individuals in their own name. If you
contribute in the course of your employment, section 4 applies; there is
not yet a separate agreement for companies.

```
I, [FULL NAME], have read and agree to the Parlance Individual Contributor License Agreement, Version [CLA VERSION]. I am at least 18 years old or otherwise legally able to enter into this Agreement, and the GitHub account identified below belongs to me.

GitHub user id: [GITHUB USER ID]
GitHub login at signing: [GITHUB LOGIN]
Date: [YYYY-MM-DD]
```

Your numeric GitHub user id is the number GitHub assigns to your account; it
does not change if you rename your login. Find it with
`gh api users/<login> --jq .id`, or open `https://api.github.com/users/<login>`
in a browser and read the `id` field. The file name must use this number,
not your login.
